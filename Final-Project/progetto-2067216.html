This project analyzes the movies.csv dataset, which contains information about movies such as “budget”, “gross revenue”, “runtime”, “score”, “votes” and “year” of release. The main objective is to study the relationship between movie revenue and the available numerical variables using multiple linear regression. The analysis also includes missing data cleaning, model selection through forward and backward stepwise selection, and an evaluation of the final model on a test set.

The forward and backward stepwise selection procedures select the same final model including “budget”, “runtime”, “score” and “votes” and excluding “year”. Since the selected predictors are the same, the estimated coefficients and the BIC values are identical. This suggests that the selected model is stable with respect to the selection method.

In the full multiple linear regression model (the initial one: lm.full), the variable “year” has a p-value of about 0.343. Since this value is much larger than the usual significance level of 0.05, “year” is not statistically significant after controlling for “budget”, “runtime”, “score” and “votes”. This means that, once the other numerical predictors are included in the model, “year” does not seem to have a relevant individual effect on “gross”. This result is also confirmed by the comparison between the full model and the reduced model without “year”. Therefore, is it preferred the model without “year” (the final one: lm.final.all), since it gives almost the same explanatory power but with fewer variables.

8) TRANING SET, TEST SET AND MSE

The value “mse.final” is the test mean squared error of my final model. The RMSE is about 100 million, meaning that the typical prediction error on the test set is around 100 million in gross revenue. This is quite large, but it is reasonable given the high variability of movie revenues and the presence of outliers. Therefore, the model has some predictive ability, but its predictions are still affected by substantial uncertainty.
